# Learnig AI

The goal of this project is to learn about artificial intelligence with Python and other machine learning libraries. 

The project was designed to predict the type of skin cancer, where the user inserts an image into the form and the system returns the type of cancer it is most likely to be.

Finally, the project was made with a simple frontend and backend, aiming to apply more focus on the machine learning script.

## 🚀 How to run

To run the project, you need a Python language on your machine. To install, go to [Python Installer](https://www.python.org/downloads/).

### 📁 Cloning repository

To clone the project, run:

        git clone https://github.com/ruansilva123/Learning_AI.git

### 🤖 Training AI

1. Open your project in a terminal:

        C:\Users\user>\GitHub\Learning_AI

2. Create a virtual machine:

        python -m venv venv

3. Init a virtual machine:

        venv\Scripts\activate

4. Go to backend folder:

        cd backend

5. Run the Python script:

        python training_ai.py

### 🤖 Run the project

1. Open your project in a terminal:

        C:\Users\user>\GitHub\Learning_AI

2. Create a virtual machine:

        python -m venv venv

3. Init a virtual machine:

        venv\Scripts\activate

4. Install dependencies:

        pip install -r requirements.txt

4. Go to backend folder:

        cd backend

5. Run the Python script:

        python main.py

6. Exit the backend folder and go to frontend folder:

        cd ..
        cd frontend

7. Init the server with Python:

        python -m http.server 5500
